# Script de génération de données de test

Ce document explique comment ajouter des données de test une fois connecté.

## Matières exemples

1. **Mathématiques** - Couleur: `#3b82f6` (Bleu)
2. **Physique** - Couleur: `#8b5cf6` (Violet)
3. **Français** - Couleur: `#ef4444` (Rouge)
4. **Histoire** - Couleur: `#f59e0b` (Orange)
5. **Anglais** - Couleur: `#10b981` (Vert)

## Tâches exemples

### Mathématiques
- **Devoir**: Exercices chapitre 5 - Échéance: Demain - Durée: 60 min
- **Révision**: Réviser les dérivées - Échéance: Dans 3 jours - Durée: 45 min
- **Examen**: Contrôle intégrales - Échéance: Dans 1 semaine - Durée: 120 min

### Physique
- **Devoir**: TP Électricité - Échéance: Dans 2 jours - Durée: 90 min
- **Révision**: Lois de Newton - Échéance: Dans 4 jours - Durée: 30 min

### Français
- **Projet**: Dissertation Baudelaire - Échéance: Dans 10 jours - Durée: 180 min
- **Devoir**: Analyse de texte - Échéance: Demain - Durée: 60 min

### Histoire
- **Révision**: Révolution française - Échéance: Dans 5 jours - Durée: 45 min
- **Examen**: Bac blanc - Échéance: Dans 2 semaines - Durée: 240 min

### Anglais
- **Devoir**: Essai 500 mots - Échéance: Dans 3 jours - Durée: 90 min
- **Révision**: Vocabulaire thème 3 - Échéance: Demain - Durée: 30 min

## Comment ajouter ces données

1. Se connecter à l'application
2. Aller sur le Dashboard
3. Cliquer sur "Nouvelle matière" et ajouter chaque matière
4. Cliquer sur "Nouvelle tâche" et ajouter chaque tâche en sélectionnant la matière correspondante
5. Cocher quelques tâches comme terminées pour voir les statistiques
